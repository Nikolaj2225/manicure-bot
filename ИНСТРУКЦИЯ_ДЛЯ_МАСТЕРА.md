# Инструкция для специалиста (мастера)

Всё управление записями происходит **только в Telegram**. Никакого компьютера, кода или сайта не нужно.

## Как открыть админ-меню
1. Откройте чат с ботом.
2. Напишите команду: `/admin`
3. Появится меню с кнопками.

## Что можно делать

### Посмотреть записи
- **Расписание на сегодня** — все записи на текущий день.
- **Расписание на дату** — выберите день из списка.
- **Свободные окна** — когда есть свободное время на выбранный день.

### Заблокировать день (отпуск, болезнь, выходной)
1. Нажмите «🚫 Заблокировать день».
2. Выберите дату.
3. Напишите причину (например: «отпуск», «болею»).
4. Готово — в этот день клиенты не смогут записаться.

### Заблокировать интервал (обед, личные дела)
1. Нажмите «⏰ Заблокировать интервал».
2. Выберите дату.
3. Напишите причину.
4. Укажите время в формате **13:00-15:30** (начало-конец).
5. Готово.

### Записать клиента вручную
Если клиент не может сам записаться через бота:
1. Нажмите «➕ Записать клиента вручную».
2. Выберите услугу, дату и время (как обычная запись).
3. Введите имя клиента.
4. Введите номер телефона клиента.
5. Введите Telegram-username клиента (например @ivan) или «-», если не знаете.
6. Бот создаст запись и пришлёт готовый текст со ссылкой.
   Скопируйте этот текст и отправьте клиенту.
   Клиенту достаточно открыть ссылку и нажать Start — тогда ему будут приходить напоминания.




## Важно
- Клиенты сами записываются через бота.
- Вы только контролируете и при необходимости блокируете дни/время или отменяете.
- Если бот не отвечает — напишите техническому человеку (вам).
- Цены и услуги меняются только через разработчика.

Если что-то не работает — просто напишите в этот чат или техническому человеку.
