# Telegram-бот записи на маникюр/педикюр

Бот для самостоятельной записи клиентов, контроля загрузки специалиста и админ-управления (форс-мажоры, отпуск и т.п.).

## Админ-меню (для специалиста)

Напишите боту команду `/admin` — откроется кнопочное меню на русском:

- 📅 Расписание на сегодня
- 📆 Расписание на дату
- 🟢 Свободные окна
- 🚫 Заблокировать день (выбор даты → причина)
- ⏰ Заблокировать интервал (дата → причина → время в формате 13:00-15:30)
- ❌ Отменить запись (список ближайших записей)

Все управление — только кнопками, без сложных команд.

Старые текстовые команды (`/today`, `/schedule`, `/block`) тоже работают, но меню удобнее.

## График работы (зашит в код)
- Пн / Ср / Пт: 10:00 – 18:30
- Вт / Чт: 9:15 – 18:30
- Сб: 9:15 – 17:00
- Вс: выходной
- Обед: 13:00 – 13:30 (слоты не пересекают)

## Установка и запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Отредактируйте `config.py`:
   ```python
   BOT_TOKEN = "ваш_токен"
   ADMIN_IDS = [ваш_id]
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. Запустите:
   ```bash
   python bot.py
   ```

База данных `bookings.db` создаётся автоматически (SQLite).

## Структура
- `bot.py` — основной файл, обработчики
- `database.py` — SQLite
- `services.py` — прайс-лист
- `schedule.py` — логика слотов и графика
- `config.py` — токен и настройки

## Примечания
- Цены в сумах (UZS).
- Слоты генерируются с шагом 15 минут.
- Для продакшена рекомендуется запуск через systemd / Docker / VPS (не polling на слабом хостинге).
- Напоминания работают, пока бот запущен.
- При необходимости можно добавить оплату, несколько мастеров и т.д.
